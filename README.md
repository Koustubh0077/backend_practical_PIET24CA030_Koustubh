# Library Book Management API

REST API built with Node.js, Express and MongoDB (Mongoose).

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and set `MONGO_URI`
3. `npm start` (runs on http://localhost:3000)

## Endpoints
- POST /books
- GET /books
- GET /books/:id
- PUT /books/:id
- DELETE /books/:id

Screenshots of the output are in the `outputs` folder.
